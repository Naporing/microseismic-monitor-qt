# 自定义频率弹窗设计

## 目标

移除频率预设框右侧常驻的自定义数值框。用户在频率下拉框中选择“自定义”时，再输入所需频率，减少控制栏占用并避免禁用输入框造成干扰。

## 交互

- 保留 `20 Hz`、`30 Hz`、`80 Hz`、`自定义` 四个下拉选项。
- 选择“自定义”时打开 Qt 数值输入对话框。
- 输入范围为 1–200 Hz，保留一位小数，步进 0.5 Hz；初始值为当前正弦频率。
- 确认后立即应用频率，并将选项文字显示为 `自定义 45.0 Hz` 一类的当前值。
- 取消后恢复选择弹窗前的频率选项与频率值，不清空现有波形。
- 切换回 20/30/80 Hz 时恢复普通的 `自定义` 文案。

## 实现边界

- 删除主窗口中的常驻 `QDoubleSpinBox` 和对应信号连接。
- 使用可替换的频率输入回调封装 `QInputDialog::getDouble`，便于无界面测试确认与取消路径。
- 不改变 100 路模型、共享定时器、信号生成器和 FFT 架构。

## 验证

- 控制栏不再包含 `customFrequencySpin`。
- 确认自定义值后，生成数据的频谱峰值与输入频率一致。
- 取消输入后，预设选择、频率与已有样本保持不变。
- 原有全部测试继续通过。
