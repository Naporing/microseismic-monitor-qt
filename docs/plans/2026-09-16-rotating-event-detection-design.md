# 轮换微震事件检测演示设计

## 目标

在不假设真实仪器通道具有空间邻近、传播延迟或距离衰减规律的前提下，让模拟事件目标可轮换、可复现，并让界面状态来自独立的数据检测结果，而不是生成器直接指定的固定通道。

## 设计

- 正常信号继续保持各通道不同的频率、相位、幅值和噪声。
- 使用固定种子的确定性调度器，每轮选择 1～3 个互不重复、且不与上一轮重复的通道注入短时冲击。
- 调度器只生成波形，检测器只接收每个通道的新采样批次。两者不共享目标信息。
- 检测器要求连续 2 个 20 ms 批次越过幅值阈值才确认事件；确认后连续正常 50 个批次（1 秒）才恢复。
- `WaveformModel` 保存最近 1 秒数据以及每路当前检测状态，绘制控件只读取模型状态。
- 1000 Hz 时每路缓存 1000 点，500 Hz 时缓存 500 点。切换采样率时清空旧缓存与检测状态，但保持模拟时间连续。
- 界面状态使用“检测到事件”，不使用“故障通道”或空间传播相关描述。

## 验证

- 调度器在相同种子下结果一致，连续多轮覆盖 1～3 个目标，相邻两轮目标不同。
- 检测器不会因单批尖峰立刻告警，连续异常后告警，并在 1 秒正常数据后恢复。
- 缓存严格限制为当前采样率对应的 1 秒点数。
- 切换采样率后旧数据和旧检测状态被清除。
- 所有既有 Qt 测试继续通过。
