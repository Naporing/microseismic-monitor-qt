# 三套监测界面设计说明

## 共同约束

- 保留 100 路波形、同屏 50 路、5 秒时间窗、单 `QTimer` 和现有模拟数据逻辑。
- 只调整主窗口布局、QSS、绘制色板和异常状态表现。
- 波形继续按五级瞬时振幅分段着色；橙色位于黄色与红色之间。
- 所有方案优先保证数据可读性与绘制性能，不增加模糊、重阴影或逐通道子控件。

## A：岩盾工业指挥台

- 深石墨背景、低饱和蓝灰层级和紧凑横向工具条。
- 控件、状态、五级阈值标尺集中在顶部；波形画布占据主要面积。
- 左侧通道编号形成固定设备轨道，每 10 路增加分组线，异常通道增加形状标记。
- 使用 `Segoe UI Variable` 和 `Cascadia Mono`，强调长期值守的清晰度。

## B：白昼科研仪器台

- 冷白背景、浅灰面板和深色文字，接近实验室采集仪器。
- 使用细分隔线代替卡片堆叠，关键数值使用等宽字体。
- 波形色调整为适合浅色画布的深色版本，黄色改用琥珀色保证对比度。
- 状态与图例采用文字、形状和颜色组合，不只依赖颜色。

## C：零光现代控制舱

- 接近黑色的低光背景，辅以靛蓝操作强调色和克制的高亮。
- 顶部模块化状态带与全幅波形甲板，使用小圆角或直角。
- 五级图例显示为连续能量标尺；只在采集状态和异常位置使用轻微高亮。
- 不使用扫描线、持续动画和大面积辉光，避免影响波形辨识与刷新性能。
